E-dit icon package

desktop/windows/icon.ico
  Multi-resolution Windows 10 icon: 16, 20, 24, 32, 40, 48, 64, 128, 256 px.

android/
  Legacy launcher icons for mdpi through xxxhdpi.
  Adaptive icon foreground layers and XML resources for Android 8.0+.
  Copy mipmap-* and values into app/src/main/res/.
  play-store-icon-512.png is the Google Play listing asset.

web/
  favicon.ico and PNG favicon sizes.
  apple-touch-icon.png for iOS home screen.
  icon-* for standard PWA icons.
  maskable-* have an opaque safe-area background.
  manifest.webmanifest and browserconfig.xml are ready to reference from HTML.
