# Устройство проекта

В одном репозитории находятся два самостоятельных приложения. Интерфейс Desktop не импортирует компоненты или стили Android, и наоборот. Общая часть содержит алгоритмы и форматы данных, но не интерфейс, хранилище или нативные подключения.

| Каталог | Назначение |
| --- | --- |
| `apps/desktop/src/` | Интерфейс, стили, состояние, хранение и интеграции Tauri |
| `apps/android/src/` | Интерфейс, стили, состояние, хранение и интеграции Capacitor |
| `packages/core/` | Преобразования текста, поиск, анализ символов, модель и выполнение пресетов, общие типы |
| `src-tauri/` | Существующая оболочка Desktop; получает `dist/desktop` |
| `android/` | Существующая оболочка Android; получает `dist/android` |
| `tests/`, `e2e/`, `benchmarks/` | Проверки логики, компонентов и отдельных предпросмотров |

У каждой версии собственные `main.tsx`, `App.tsx`, компоненты и `index.css`. Ширина окна не выбирает платформу. Разделение проверяется командой `npm run check:boundaries`: запрещены зависимости приложений друг от друга, импорты интерфейса из core и подключение нативных библиотек чужой платформы. Core дополнительно проверяется TypeScript без DOM.

Предпросмотр: `npm run dev:desktop` (5173) и `npm run dev:android` (5174). Подготовка файлов интерфейса: `npm run build:desktop` и `npm run build:android`. Для браузерных тестов `npm run build:previews` создаёт отдельные `dist/desktop-preview` и `dist/android-preview`, с браузерной заменой файловых операций. Эта замена исключается из нативной сборки при компиляции; browser file picker для импорта Android остаётся частью его штатной интеграции.

## Текст и сохранение

`useEditor` управляет отдельным редактором и его Undo/Redo. `EditorPersistence` немедленно записывает журнал восстановления в localStorage, затем согласованно сохраняет текст и History в IndexedDB. Импорт и экспорт ожидают завершения отложенных записей. Undo содержит временные шаги текущего запуска; History хранит до 50 версий отдельно для каждого редактора.

Версия приложения (`2.0.6`), формат экспорта (`3`) и схема базы (`5`) независимы. Не повышайте формат данных только из-за изменения версии приложения. Импорт Data v2 и миграции старых баз должны продолжать работать.

Имена баз, схемы, ключи настроек и идентификаторы нативных приложений сохранены. У каждой установленной версии своё хранилище; синхронизация между ними не добавляется. У предпросмотров разные порты, поэтому их данные также разделены.

## Действия и интерфейс

`apps/<платформа>/src/lib/actions.ts` описывает действия, `actionShortcuts.ts` разрешает сочетания и конфликты. `useActionShortcuts` вызывает действия с учётом активного редактора, открытого окна и фокуса. Алгоритм новой команды добавляется в core, а её доступность и представление определяются каждым приложением отдельно.

`useWorkspacePanels` отвечает за единственную открытую панель и восстановление позиции редактора. `useDialog` объединяет поведение диалогов. Набор шагов пресета проверяется перед применением и изменяет текст одним шагом Undo.

## Границы проверок

Браузерные mobile-сценарии проверяют размеры и навигацию, но не настоящую экранную клавиатуру и системные диалоги Android. Сборка нативного пакета подтверждает компиляцию и упаковку; её нельзя считать проверкой установленного приложения.
