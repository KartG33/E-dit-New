## Зависимости

Исходный `npm audit`: 17 предупреждений, из них 3 высокой серьёзности. Совместимыми обновлениями исправлены `@xmldom/xmldom`, `nanoid`, `postcss`, `undici`; Capacitor CLI обновлён с 8.5.0 до 8.5.1. Инструменты Tailwind перенесены в `devDependencies`.

Полный `npm audit` после исправлений — **0 известных уязвимостей**.

Последнее [уведомление uuid](https://github.com/advisories/GHSA-w5hq-g745-h8pq) устранено ограниченным `overrides.xcode.uuid = 11.1.1`. Причина override: `xcode@3.0.1`, вложенная зависимость Capacitor CLI для iOS, всё ещё требует старую библиотеку. Проверены поддержка CommonJS в 11.1.1 и единственный используемый вызов `uuid.v4()`; через API установленного `xcode` получены 1 000 корректных уникальных идентификаторов. Принудительный откат Capacitor CLI не применялся. После перехода `xcode` на исправленную зависимость override следует убрать вместе с повторной проверкой CLI. CI показывает аудит и блокируется при высокой/критической серьёзности.

## Границы изменений

Старые ветки и worktree сохранены; история Git не переписывалась. `main` остаётся основной веткой. Лицензия в проекте не была задана; новые условия распространения от имени владельца не добавлялись. Защита `main` на момент аудита отключена; автоматическое требование PR/ревью не включалось, чтобы не менять порядок работы владельца. Подписанный релиз и автоматическое обновление приложения требуют отдельной настройки выпуска.

Проверки выполняются без подключения смартфона. Нативные сборки CI подтверждают компиляцию и упаковку, но не испытание установленного приложения. Предыдущие локальные пакеты и их хеши описаны отдельно в [проверке реализации](verification-2.0.6.md).
