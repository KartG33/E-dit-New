# Проверка согласованных улучшений E-dit 2.0.6

Дата: 8 сентября 2026 года.

## Реализованные сценарии

| Область | Результат |
| --- | --- |
| Сохранение | Немедленный журнал восстановления, согласование отложенных записей с импортом/экспортом, видимые ошибки и повтор сохранения |
| Пресеты | Упорядоченные команды, обычные/regex-замены и удаление фрагментов в одном пресете; независимое дублирование; один шаг Undo |

| Окна и навигация | Единое управление открытой панелью, закрытие по фону и Esc, восстановление выделения/прокрутки, последняя вкладка |
| Поиск текста | Буквальный поиск, регистр, счётчик, следующий/предыдущий результат и заметное выделение без изменения текста |

| History | Поиск по полному тексту всех сохранённых версий, фильтр редактора, дата/время, живое обновление; восстановление одним нажатием |
| Keys | Назначение, удаление и сброс сочетаний; команды, навигация и пресеты; проверка конфликтов, хранение и импорт/экспорт |
| Подсказки | Сочетания показываются в настройках и при наведении, постоянные подписи у команд убраны |
| Сообщения | Неблокирующие результаты, точное число замен/удалений, сообщение при отсутствии изменений |

Браузерные сценарии проверяют перезапуск до отложенного сохранения, экспорт последнего текста, импорт при ожидающей записи, составные пресеты и независимый Undo, сохранение/конфликты горячих клавиш, поиск и повторяющиеся теги. Отдельный сценарий проверяет открытие инструмента неактивного редактора и возврат именно к нему.

Визуально проверены 1280×720, 360×844, 393×844, 412×844 и 844×393; навигационный сценарий также использует 1280×800. Все кнопки редактора помещаются на 360 px. Найденный фрагмент выделен даже при фокусе в строке поиска; появление панели символов и изменение размера редактора корректируют его положение.

Поиск проверен на 99 009 символах с пределом сценария 3 секунды, составной пресет — на 100 000 символах с проверкой полного результата и последней строки.

## Ограничения и окружение

- По уточнению пользователя смартфон не подключается и не используется. Выполненная ранее команда `adb devices` показала пустой список; установки приложения на телефон не было. Дальнейшие ADB-действия исключены.
- Поведение настоящей экранной клавиатуры, внешней клавиатуры Android и системных мобильных диалогов в этой итерации на устройстве не проверялось. Есть компонентные/адаптерные тесты, но они не заменяют испытание на устройстве.
- Нативный запуск Windows и системные диалоги Windows на последней сборке отдельно не проверялись. Сборка и адаптерные тесты не означают полноценный ручной прогон.
- Сборка MSI остановилась на запуске локального WiX `light.exe`; NSIS-установщик собирается успешно.
- Под нагрузкой параллельных нативных сборок встречались таймауты запуска Vitest workers и ожидания загрузки UI. Для итоговой проверки используется один thread worker без увеличения таймаутов тестов.
- Установленный JDK Android Studio оказался неполным. Для сборки использован переносимый JDK 21 из официального репозитория [Adoptium Temurin](https://github.com/adoptium/temurin21-binaries/releases), с проверкой опубликованной SHA-256. Он находится в игнорируемом `temp/android-build`; системные настройки Java не менялись.

Рабочие изменения не опубликованы и не устанавливались поверх пользовательского приложения.
